Componentes Visuales con JS

Tarjeta giratoria y carrusel de imágenes

Tarjeta giratoria

Muestra una imagen al frente y la información atrás. Dale clic para voltearla.

Carrusel de imágenes

Avanza solo, se desliza con el dedo o el mouse y funciona con las flechas del teclado.

Código

Así de fácil se usa

1. Incluye el CSS y el JS

<link rel="stylesheet" href="css/componente.css">
<script src="js/componente.js"></script>

2. Tarjeta giratoria

<div id="miTarjeta"></div>

<script>
  crearTarjeta('#miTarjeta', {
    imagen: 'img/foto.jpg',
    titulo: 'Ajolote',
    texto: 'Puede regenerar partes de su cuerpo.',
    color: '#db2777'
  });
</script>

3. Carrusel de imágenes

<div id="miCarrusel"></div>

<script>
  const carrusel = new Carrusel('#miCarrusel', {
    altura: '420px',
    intervalo: 5000,
    slides: [
      { imagen: 'img/foto1.jpg', titulo: 'Playa', texto: 'Arena blanca' },
      { imagen: 'img/foto2.jpg', titulo: 'Bosque', texto: 'Aire fresco' }
    ]
  });

  carrusel.siguiente(); // también: anterior(), irA(0), pausar(), reproducir()
</script>
